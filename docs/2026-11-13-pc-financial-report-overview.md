# PC 端门店财务报表功能与统计口径汇总

更新日期：2026-11-13。本文汇总当前已实现的电脑端月度财务报表，供业务查看、需求核对和后续维护使用。

核对基线：功能提交 `4d928c7`，生产 API / 管理端版本 `deploy-20261113-paid`，数据库迁移 `20261113_0048`。本文为功能说明，不代表已为任何审批单启用实付入账。

## 一、入口与查看范围

| 项目 | 说明 |
| --- | --- |
| 全局入口 | 左侧“报表与审计 → 财务报表”，路径 `/reports` |
| 门店入口 | 进入具体门店账套，选择“财务报表” |
| 页面关系 | 两个入口复用同一个报表组件，指标口径一致 |
| 查询范围 | 选择一个授权门店和一个月份查看月报 |
| 账期状态 | 显示“进行中”或“已封账”，未封账月份可查看 |
| 历史累计范围 | 当前门店截至所选月份，包含当期；不是所有门店合计 |
| 数据状态 | 未封账数据会随入账、匹配、计提及分红维护更新 |

## 二、页面板块与字段

### 1. 门店营收

| 字段 | 说明 |
| --- | --- |
| 营业收入 | 当月报表收入 |
| 本月业绩目标 | 当前门店、当前月份维护的目标；未录入显示待录入 |
| 业绩完成率 | 营业收入 ÷ 业绩目标；目标缺失或为零时不计算 |
| 实收 | 营业收入记录的实收金额，不是净利润或银行卡余额 |
| 手续费 | 营业渠道手续费汇总 |
| 手续费率 | 手续费 ÷ 营业收入 |

下方“各渠道经营收入明细”按渠道展示经营收入、实收、手续费、手续费率和收入占比，按经营收入降序排列。渠道取自实际收入记录，例如美团团购、抖音团购、扫码收款等。

### 2. 门店支出

| 字段 | 说明 |
| --- | --- |
| 总支出 | 当前月份按报表规则确认的经营支出 |
| 营业毛利率 | （营业收入 − 食材成本）÷ 营业收入，同时展示食材成本金额 |
| 营运费用占比 | 运营费用 ÷ 营业收入，同时展示运营费用金额 |
| 薪资占比 | 人工成本 ÷ 营业收入，同时展示人工成本金额 |
| 本月计提、补提、冲销 | 有相关金额时显示；计提、补提已包含在总支出，冲销已扣减，不另重复累加 |

### 3. 资金流情况

- **其他应收款 · 外借款**：截至所选月末尚未归还的借出本金，不计入经营利润。
- **银行卡余额**：当前门店、当前月份人工维护的报表展示余额，注明“截至某日期余额”；没有录入时显示待录入。
- 有借款记录时展示借款人、借出本金、累计归还、未还本金和状态。
- 可展开借出、还款事件，查看日期、类型、金额、备注、是否撤销及凭证。

报表展示余额与银行流水页面的余额是两套数据：前者为报表人工维护；后者依据银行余额基准和后续实际流水计算，不能互相替代。

### 4. 利润分红

| 字段 | 说明 |
| --- | --- |
| 本月净利润 | 营业收入 − 总支出 |
| 上月末未分配利润 | 上月结余；分红启用首月取配置的期初未分配利润 |
| 剩余未分配利润 | 分红管理对应月份的结余 |
| 本月分红 | 当月股东分红金额 |
| 本月补充筹建超支 | 使用利润补充筹建超支，扣减未分配利润，不计作股东分红 |
| 本月运营增资 | 当月运营注资金额 |
| 历史累计利润 | 期初历史利润加启用后的净利润，截至本月 |
| 历史累计分红 | 期初历史分红加启用后的分红，截至本月 |

分红期初配置之前的隔离月份，相关未分配利润字段显示“隔离前”，不能直接按启用后的月份理解。

### 5. 投入与累计

- 筹建投入资金。
- 筹建费用总支出：筹建报表已封账时读取其总支出；未封账时使用已维护的人工金额，没有可用金额则显示待录入。
- 筹建结余或筹建超支：筹建投入资金减筹建费用总支出；超支显示正数绝对值。
- 下方说明经营利润已补充金额和超支未补充金额。
- 累计投入：筹建投入加截至本月的运营增资。
- 累计分红：截至本月的累计股东分红。

### 6. 核心成本率结构

展示食材成本、人工成本、租金成本的金额、成本率和占比条形图。当前没有单独的“核心食材（鸡、菌子）”板块。

### 7. 支出分类排行

按费用分类金额展示支出排行图，便于查看主要支出构成。

### 8. 各类别支出统计

分为“食材成本”和“运营支出”两个区域。运营支出区域为总支出减食材成本。

每个区域展示总金额、占营业收入和占总支出的比例。分类表包含：

| 字段 | 说明 |
| --- | --- |
| 费用分类 | 可展开分类层级，点击查看费用明细 |
| 金额 | 当月该分类入账金额 |
| 占营业收入 | 分类金额 ÷ 当月营业收入 |
| 占总支出 | 分类金额 ÷ 当月总支出 |
| 历史累计支出 | 当前门店截至所选月份、包含当期的该分类累计入账金额 |
| 条数 | 对应分类费用记录条数，不等同于付款流水笔数 |

费用明细弹窗展示日期、费用内容、金额及报销凭证；计提、补提、冲销附类型标签，银行直接入账费用可查看原流水。凭证支持图片预览及文件打开/下载。

### 9. 计提与冲销费用

单独列出计提、补提、冲销，按费用分类排序，展示分类、日期、费用内容、入账金额、图片凭证。

这些金额已经计入各类别和总支出，单独展示不再次累加；冲销明细为负数。

### 10. 特殊流水

展示特殊属性流水及直接入账流水，包括往来款、股东分红、股东注资、其他收支、退款、借还款、银行结息、其他收入、银行手续费、银行短信费及银行其他支出等。

字段包括发生日期、所属账期、入账月份、流水属性、方向、金额、对方户名、备注和原流水入口。

是否影响利润取决于对应的入账规则，不能把本表所有收入或支出直接相加作为利润。该表本身不重复累计金额。

### 11. 主要支出凭证

展示费用名称、所属账期、总展示金额、附件、备注、录入时间，并显示本账期凭证数量和展示金额合计。

**仅用于归档与展示，不计入总支出、毛利和净利润。**

## 三、入账与去重规则

### 1. 日期与月份

- 营业收入按收入日期统计。
- 审批费用按审批单的入账月份统计，银行流水发生日期不决定审批费用归属。
- 未配置多账期时，一张审批单只归属一个入账月份；历史无统一方案的单据，以第一笔仍有效的确认匹配记录所设置的入账月份确定归属。
- 配置了多账期方案，才按指定月份和金额分摊费用。
- 单张审批单关联多笔流水，只代表分批付款，不能在每个付款月份重复计入整单金额。
- 银行结息、银行手续费、其他收入等直接入账流水按发生日期所属月份及各自规则统计。

### 2. 按审批金额与按实付金额

| 方式 | 入账金额 | 入账月份 |
| --- | --- | --- |
| 默认按审批金额入账 | 审批费用金额或显式分配方案金额 | 审批单入账月份/指定分摊月份 |
| 以实付金额入账 | 累计有效确认且已实付的匹配金额，按原明细比例分摊到分 | 启用时确定的审批单统一入账月份，与银行日期无关 |

“以实付金额入账”在“审批单对账 → 未匹配满审批单”按单启用，也可恢复审批金额入账；不会自动批量启用。启用不等于匹配完全，后续匹配、解除及付款状态变化会重算金额。已经设置多月份分摊的单据，须先明确单一入账月份再启用该模式。具体设计见[实付入账说明](2026-11-13-paid-approval-accounting.md)。

### 3. 计提关联

- 计提先按其入账月份确认费用；补提增加费用，冲销减少费用。
- 审批单被计提单**整单关联**后，审批费用不再次计入报表，即使启用了实付金额入账也一样。
- 已有按审批明细关联的场景，排除被选中的明细，其余部分按现有规则正常入账。
- 付款匹配照常保留，不因计提排除而删除流水或付款记录。

### 4. 非经营支出与资金往来

门店预充值、备用金/借款、异常费用按分类规则排除经营支出。外借及归还本金作为资金和应收变动，不作为经营利润。股东分红、注资、筹建超支补充分配也不能当作普通经营费用重复计费。

### 5. 封账与更正

未封账数据可以随业务变化更新；封账后的相关入账调整受校验限制。若审批来源撤销、修改等导致已出账数据需要核对，应走审批变更核对及财务更正流程，不能通过改变流水日期代替费用月份调整。

## 四、页面操作

| 操作 | 作用 |
| --- | --- |
| 切换门店、月份 | 查看对应门店月报 |
| 查看账期状态 | 区分进行中与已封账 |
| 设置业绩目标 | 维护当前门店月份的目标及完成率 |
| 录入报表余额 | 维护余额、截止日期及修改原因；不改变流水页面余额基准 |
| 点击费用分类 | 查看明细、入账金额和凭证 |
| 查看借还款凭证 | 展开借款记录及事件凭证 |
| 查看原流水 | 从直接入账费用或特殊流水追溯来源 |
| 导出 HTML / PDF | 保存当前门店月份的报表及业务附录 |

目标及报表余额等维护操作受账号权限和封账状态约束。

## 五、HTML 与 PDF 导出

导出包含主要指标、渠道收入表、核心成本率、分类统计及历史累计、计提与调整、特殊流水、支出明细、主要支出凭证（有记录时）、流水业务附录和相关图片凭证。

| 内容 | 展示方式与注意事项 |
| --- | --- |
| 渠道收入 | 使用表格，已移除原营业收入渠道条形图 |
| 核心成本率 | 展示食材、人工、租金；不再单列核心食材板块 |
| 支出明细 | 按银行流水分组，列示流水、支出日期、二级分类、费用内容、申请报销日期、本期详情金额 |
| 多条费用明细 | 同一笔流水可以对应多行费用；“流水 N（明细续行）”仍属于同一笔流水，不代表新增付款 |
| 重复关联 | 同一费用关联多笔流水时避免重复展示/累加本期费用金额；流水金额可能与本期费用金额不同 |
| 无流水费用 | 计提、采购等按相应来源单独列示 |
| 手续费 | 收入渠道和支出统计按规则展示；导出支出明细表不逐条重复列手续费明细 |
| 流水业务附录 | 展示流水发生日期、方向、对方户名、流水金额、属性及关联报销/收入业务说明 |
| 图片凭证 | 可包含计提及借还款图片凭证；凭证是否有内容取决于实际上传和获取结果 |

页面与导出采用一致的财务金额口径，但布局不完全相同：页面支持交互展开，导出提供适合阅读和打印的明细、分组及附录。

## 六、相关功能边界

- “分红管理”为独立业务页面，负责期初、分红、增资及筹建超支补充分配等维护；财务报表展示其对应结果，不代表报表内提供全部维护操作。
- “筹建费用”为独立页面；月度财务报表只引用相关汇总，不把筹建费用全部重新计入月度经营费用。
- 银行流水列表及流水业务详情为来源查询页面；流水金额、报表费用、报表余额是不同指标。
- 报表页的计提明细、特殊流水及主要支出凭证均有独立用途，不能再把这些展示金额加到总支出上。
