#### 核心优化点

**操作流程对比**

旧流程（7步）：
```
1. 点击"新增匹配"
2. 打开弹窗
3. 选择支出明细（下拉搜索）
4. 选择银行流水（下拉搜索）
5. 输入金额
6. 点击确认
7. 关闭弹窗，刷新列表
```

新流程（3步）：
```
1. 点击左侧流水（自动选中）
2. 点击右侧推荐匹配的"确认"
3. 自动跳转下一条（无需手动操作）
```

**效率提升：操作步数减少 57%（7步 → 3步）**

#### 智能推荐算法

```typescript
// 置信度计算规则
金额完全匹配（<0.01差异）：+50 分
金额接近（<5%差异）：      +30 分
金额小于流水金额：          +20 分

供应商名称匹配：            +30 分

日期差异 ≤3天：            +15 分
日期差异 ≤7天：            +10 分

摘要关键词匹配：            +15 分

总分上限：98 分
```

**分级标准：**
- 高置信度：≥90 分（绿色边框，推荐优先确认）
- 中置信度：70-89 分（黄色标识）
- 低置信度：<70 分（灰色标识）

## 使用指南

### 基本操作流程

**1. 进入匹配工作台**
```
导航：左侧菜单 → 匹配工作台
或直接访问：/matching-v2
```

**2. 选择待匹配流水**
- 在左侧列表点击任意流水
- 使用搜索框快速定位
- 使用筛选器过滤

**3. 查看智能推荐**
- 右侧自动显示推荐匹配
- 查看置信度和匹配原因
- 金额完全匹配会高亮显示

**4. 确认或拒绝**
- 点击"确认匹配"立即确认
- 点击"拒绝"跳过此推荐
- 系统自动跳转下一条

**5. 手动处理**
- 无推荐时点击"手动搜索"
- 自定义匹配关系

### 快捷筛选技巧

**按门店筛选**
- 适用场景：集中处理某个门店
- 操作：下拉选择门店

**按状态筛选**
- "未匹配"：只显示有剩余金额的
- "已完全匹配"：查看已完成的

**搜索技巧**
- 输入供应商名称
- 输入关键词（如"餐饮"）
- 支持模糊搜索

### 最佳实践

**1. 从高置信度开始**
- 优先处理绿色边框的推荐
- 置信度 ≥90% 的通常很准确

**2. 注意金额核对**
- 确认前检查金额是否匹配
- 部分付款时注意剩余金额

**3. 利用自动跳转**
- 确认后无需手动找下一条
- 提高连续处理效率

**4. 定期使用自动生成**
- 点击"自动生成候选"
- 系统批量生成推荐
- 然后逐条确认
