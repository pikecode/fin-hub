# 钉钉审批同步漏数修复说明

日期: 2026-09-07

## 问题

线上 `dingtalk` 页面手动点“同步审批单”时，默认只回溯最近 7 天。
这会让很多更早但仍然应该入库的审批单看起来“没有同步过来”。

另外，单次同步的分页上限偏小，历史量大时容易提前截断。

## 结论

这不是钉钉去重本身导致的主因，主要是同步窗口太窄、分页上限偏低。

## 修复

1. 手动同步默认回溯窗口改为最近 120 天。
2. 单次同步分页上限提高到 500 页。
3. 门店账期同步也同步抬高分页上限，减少漏扫。
4. 界面文案改成和实际行为一致，避免让人误以为“只同步 7 天”。

## 预期效果

- 首次手动同步能覆盖更大的历史范围。
- 历史审批单更容易被补回。
- 自动同步和门店同步在高数据量场景下更不容易提前截断。
