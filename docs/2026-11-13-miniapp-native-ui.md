# 小程序移动端视觉与交互优化

状态：开发与本地验证完成；已编译微信生产包，未上传微信、未切换体验版，未完成iOS/Android真机验收。生产API、PC报表及财务数据未修改。

## 交互结构

底部保留“报表、银行流水、分红管理、我的”四个原生入口。银行流水与分红使用独立图标；门店在页面顶部切换，不新增门店tab。月份使用原生选择器，银行流水保持不受账期限制。

报表页先展示本月净利润、营业收入和总支出，导出入口为次级操作；完整数据按四个分区展示，替换原先11个锚点按钮与一次性长列表。

| 分区 | 包含内容 |
| --- | --- |
| 经营概览 | 门店营收、目标/完成率、实收/手续费、收入渠道、门店支出、计提/补提/冲销汇总、核心成本率 |
| 支出分析 | 分类排行、食材成本和运营支出、一级/二级分类金额与占比、历史累计、计提冲销明细及凭证 |
| 资金分红 | 资金流/报表余额、外借款、借还事件及凭证、利润分红、投入与累计 |
| 流水凭证 | 延迟读取特殊流水、分页加载、原流水详情、主要支出归档及附件 |

渠道默认展示前三项、排行默认展示前五项，可展开全部。分类默认呈现一级汇总，点击展开二级分类；费用明细使用独立入口，避免展开与跳转混淆。主要金额、计提冲销、凭证和历史累计未删减。

## 各页面行为

- 银行流水：余额卡片与流水列表分离；顶部原生日期筛选和关联状态，支持清除筛选；收支方向、金额、关联状态分层展示。点击整行查看关联业务，“流水信息”入口查看完整字段，保留分页。
- 流水详情：金额/户名/日期摘要在前，“关联业务”和“流水信息”分区切换；保留完整账号、流水号、备注、付款状态、入账月份和凭证访问。
- 分红管理：所选月份优先，月度卡片先展示分红、净利润及未分配利润；完整计算明细、股东记录点击展开；投入与累计单独折叠，所有历史月份仍可查看。
- 登录：字段标签、密码显示/隐藏、键盘提交、忙碌态与清晰错误反馈；保持原认证接口，不保存密码到本地。
- 我的：账号摘要、可访问门店列表、折叠密码表单、退出确认。门店数量从已有授权门店接口读取，避免管理员以直接授权数0误判无门店。
- 费用明细/凭证：日期、金额、费用说明和文件入口分层；有重试、无数据和无附件状态；原鉴权下载、图片预览及文件打开行为保留。
- 导出：简化为月份/内容说明、生成进度、PDF打开和HTML转发；保留任务轮询、失败重试、24小时有效及下载授权，不改文件内容生成逻辑。

## 刷新与状态

报表、流水和分红启用原生下拉刷新，重新读取门店、月份和当前数据。相同门店月份刷新时保留报表分区，特殊流水也重新读取；请求版本校验避免旧返回覆盖新数据。未授权门店、没有账期、空记录与网络错误分别提示，避免把权限/缺账期显示成金额0。新增授权后可下拉取得门店列表；没有账期时仍可进入独立银行流水。

使用浅灰背景 `#f4f6f7`、白色卡片、深绿摘要 `#194d40` 和主操作 `#22634e`。正文金额采用等宽数字，主要按钮以88rpx点击区域为基准。次要财务文字加深，重点优化手机窄屏的金额换行和长说明。

共享列表、空态、金额和附件样式放在全局app样式，保证微信独立详情页不依赖首页组件CSS。原生tabbar图标保留81px PNG，银行/分红另保留SVG源文件；无新增运行依赖。
