## 💡 关键改进

### 1. MoneyDisplay - 金额显示统一

```tsx
// 优化前
{formatMoney(amount)} // 20+ 种不同写法

// 优化后
<MoneyDisplay value={amount} colorize />
```

**效果**:
- 自动格式化（千分位、小数）
- 颜色编码（收入/支出）
- 右对齐便于对比
- 代码一致性 100%

---

### 2. StatusBadge - 状态显示标准化

```tsx
// 优化前
<Tag color={status === 'paid' ? 'green' : 'red'}>
  {status === 'paid' ? '已付款' : '待付款'}
</Tag>

// 优化后
<StatusBadge status="paid" text="已付款" />
```

**效果**:
- 预定义 8 种状态类型
- 统一视觉语言
- 图标 + 颜色 + 文字
- 可访问性更好

---

### 3. EnterpriseTable - 表格功能企业化

```tsx
// 优化后
<EnterpriseTable
  columns={columns}
  dataSource={data}
  exportFileName="营业收入"
  batchActions={[
    {
      key: "delete",
      label: "批量删除",
      danger: true,
      onExecute: async (keys) => {
        // 批量删除逻辑
      },
    },
  ]}
/>
```

**新增功能**:
- ✅ 批量选择/操作
- ✅ 导出 (CSV/Excel/JSON)
- ✅ 列显示/隐藏
- ✅ 密度切换
- ✅ 全局搜索
