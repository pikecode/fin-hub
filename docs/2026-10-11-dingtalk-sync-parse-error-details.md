# 同步费用解析异常明细

## 背景

同步日志只有“10 条费用解析异常”等汇总信息，无法定位具体审批单与缺失字段。该次服务器异常包括金额无效、总部部门未明确门店、审批门店名称与本地门店不一致。

## 功能

- 钉钉同步执行日志新增“查看解析异常”入口，仅费用解析异常任务展示。
- 弹窗按列表显示审批编号（可复制）、审批模板、源门店或部门、中文异常原因及处理建议。
- 包含请求加载状态、错误展示和重试；长文本换行，列表分页，小屏可横向滚动。
- 新同步任务在结果摘要保存解析异常快照，后续修改审批不会覆盖任务当时的异常原因；自动同步的嵌套审批摘要同样支持。
- 旧日志没有快照时，查询仍关联该任务的当前异常，并明确提示已修复或再次同步的单据可能不再显示。
- 新接口 GET /api/dingtalk/sync-jobs/{job_id}/parse-errors，沿用钉钉查看权限。
- 不自动更改审批金额、门店归属或对账数据，不伪造历史快照。

## 验证

后端覆盖历史任务查询、中文字段原因、总部部门处理建议、自动任务摘要快照在单据修复后保持不变、无效任务返回 404；前端 TypeScript 检查通过。

## 部署验证

前后端已部署 `deploy-20261011-parse-details`。服务器当前 10 条异常任务可返回 10 条明细，每条包含编号、原因及建议。公网登录页面、20 个引用静态资源及 API 健康检查均为 200；前后端容器重启次数为零。配置备份保存在 `/opt/fin-hub/releases/deploy-20261011-parse-details/env.production.before`。每日调度、业务数据及历史失败日志保持原状。
