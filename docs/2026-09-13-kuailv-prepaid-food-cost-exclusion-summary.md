# 门店预充值排除规则修改总结

## 背景

门店套帐总览页的“本期支出”和“毛利”原本会把所有已确认入账的支出计入统计。实际业务中，一级分类 `门店预充值` 下的支出属于预充值款，不是当期真实消耗或实际支出。如果计入本期支出，会放大当月支出；如果计入食材成本，会压低毛利。

影响页面：

- `/store-ledgers/[storeId]?period=YYYY-MM`
- 示例：`/store-ledgers/c2487f279b5140c190521b5695075d73?period=2026-08`

## 修改内容

在门店套帐总览接口中新增排除规则：

```text
category_l1 == "门店预充值"
```

符合该规则的已确认审批入账支出会从总览统计中排除。历史数据中的 `食材成本 / 快驴充值` 仍兼容排除。

修改位置：

- `apps/api/app/modules/store_ledgers/router.py`

## 调整后的口径

### 本期支出

调整前：

```text
本期支出 = 已确认入账审批支出 + 当月手续费支出
```

调整后：

```text
本期支出 =
  已确认入账审批支出
  - 门店预充值
  + 当月手续费支出
```

其中“已确认入账审批支出”仍按 `expense_bank_matches.accounting_period` 归属账期，不按银行流水发生月直接归属。

### 食材成本

调整前：

```text
食材成本 = 已确认入账审批支出中 category_l1 == "食材成本" 的金额
```

调整后：

```text
食材成本 =
  已确认入账审批支出中 category_l1 == "食材成本" 的金额
```

### 毛利

毛利公式保持不变：

```text
毛利 = 经营收入 - 食材成本
```

由于 `门店预充值` 已从本期支出和食材成本中排除，因此该预充值款不会扣减毛利。

### 支出分类统计

`门店预充值` 同步从总览页的“支出分类统计”中排除，避免分类表与指标卡口径不一致。

## 不变内容

- 当月手续费支出 `source == "revenue_fee"` 仍计入本期支出。
- 其它食材成本二级分类，例如 `食材成本 / 肉类`，仍按原规则计入本期支出和食材成本。
- 未确认匹配、候选匹配、已拒绝匹配的支出仍不计入本期支出。

## 测试验证

新增回归测试：

- `test_store_ledger_workspace_excludes_prepaid_kuailv_food_cost`

测试覆盖：

- 普通食材成本已确认入账后，正常计入本期支出。
- `门店预充值` 已确认入账后，不计入本期支出。
- `门店预充值` 不计入食材成本。
- 毛利只扣减真实食材成本。
- 支出分类统计不展示 `门店预充值`。
