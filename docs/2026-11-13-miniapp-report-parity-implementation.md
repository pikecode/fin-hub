# 小程序报表对齐实施与发布说明

基于[设计方案](2026-11-13-miniapp-report-parity-design.md)和[PC报表清单](2026-11-13-pc-financial-report-overview.md)实施。更新日期：2026-11-13。

## 已实施：完整在线报表

功能提交 `55bd953`。

- tabbar仍为报表、银行流水、分红管理、我的，报表内保留财务报表及营业收入。
- 独立FinancialReport组件覆盖PC11类报表板块，增加章节跳转、完整分组指标、渠道收入占比、分类树/历史累计、计提明细及凭证、借款事件、特殊流水懒加载和主要支出凭证。
- PC与小程序共用shared-utils中的reportGroups、reportPercent、reportCategorySections、buildReportCategories，避免两端自行定义指标/分类层级。
- 同源report_expense_items覆盖审批、显式分配/实付模式、计提、采购、渠道手续费和银行直接入账；PC分类弹窗及小程序费用详情使用同一服务。分类明细支持父级查询、分页、总条数及总金额。
- 报表接口增加major_vouchers、retrieved_at、contract_version；增加特殊流水及资源附件查询接口，保持旧接口字段兼容。
- 凭证支持expense_item与loan_event，附件元数据、下载均沿用后端门店范围鉴权。
- 继续股东只读，不增加目标、余额、匹配、计提或分红的写入功能。

## 已实施：HTML/PDF导出链路

- 新增financial_report_exports与迁移0049。任务保存门店月份、所有者、状态、期限及完成后的报表快照；文件在FILE_STORAGE_ROOT/report_exports下按随机任务ID存放。
- POST `/api/miniapp/report-exports`创建任务；GET `/{id}`查询；GET `/{id}/download?format=pdf|html`鉴权下载。
- 单个任务在REPEATABLE READ只读事务中读取报表、补充指标、同源费用明细、业务附录和凭证；HTML/PDF使用相同数字快照及图片字节。
- 包含完整指标、渠道、成本率、分类累计、计提调整、借还款、特殊流水、分组支出明细、主要凭证、流水业务附录和图片凭证。
- 支出明细区分流水总额和本期费用，明细续行不代表新付款，同一费用多笔关联不重复累计。无流水费用单列，手续费不逐条重复展示。
- 增加reportlab运行依赖，PDF使用CJK字体，支持中文多页表格及重复表头；HTML为独立文件，图片以data URL内嵌。非图片文件及未能嵌入图片列入警告，提示在小程序查看原件。
- 小程序增加导出状态页，PDF使用微信文件查看能力；HTML尝试微信文件转发，不支持时提供本地保存说明。

### 运行方式与限制

当前采用FastAPI BackgroundTasks及数据库持久任务记录，没有新增Celery服务。每个API进程最多2个渲染任务，全局待处理上限8，每个用户最多2个待处理任务；pending任务可在查询时重新调度，running超过15分钟标记失败，用户重新生成。多API进程的并发上限按进程分别计算，后续大规模使用可替换独立队列worker。

文件默认24小时内有效；查询和下载均实时校验登录状态、任务所有者与门店授权。到期文件在创建新任务时按批清理；如无新任务，磁盘上可能暂存过期文件，但下载接口拒绝访问。部署环境可定期调用清理流程或另配运维清理任务。

单次导出限制凭证数量与图片容量；图片缩放后嵌入。缺失、格式不支持或远端下载失败的凭证不会伪装为完整嵌入，任务和文件明确显示警告。导出为读取快照，不锁定或封账业务数据；生成之后发生的业务变化需重新生成。

PC现有HTML/PDF生成入口继续保留，本轮未替换PC导出引擎。在线指标和分类展示函数已共用；服务端导出复用PC同源数字服务，并对渲染字段做跨端值校验，不声称PDF布局像素级相同。

## 部署与验收边界

目前未部署本轮API/PC改动，未上传新的小程序版本，也未进行iOS/Android真机验收。微信HTML转发及文件保存能力需真机确认；后台任务重启及多进程资源情况需部署环境验证。

上线顺序：先备份并安装API新依赖、升级0049、发布兼容读取与导出接口；同步发布PC共用明细/展示改动；再构建并上传小程序开发版本，设置体验版进行真机验收。用户尚未在本轮授权发布，开发完成不能代替生产上线。

回滚须保留导出任务表和文件备份；可停用新入口再切回兼容版本，不默认downgrade或恢复数据库。在线阶段无迁移，导出阶段引入0049及reportlab依赖，不能仅覆盖API代码却漏装依赖。各批代码、文档及本地before/after备份参见CHANGELOG，尚未推送远程。
