# 审批单对账明细分类优化方案

## 目标

审批单对账时，分类录入要和审批明细对齐：

1. 如果审批单有明细，优先对明细逐条录入分类。
2. 确认匹配时，只保存明细分类，不再只写审批主单一个分类。
3. 明细分类支持批量选择，减少重复操作。
4. 明细展示补充报销凭证信息，方便核对。

## 现状

当前确认弹窗里只有一个“费用分类”字段，实际会把分类写到当前选中的费用项上。
审批单如果有多条明细，用户仍然需要逐条点选，体验和业务粒度不一致。

## 方案

### 1. 分类输入层级

- 审批单有明细时，展示明细表格。
- 每条明细都可以单独选分类。
- 允许对多条明细批量套用同一个分类。
- 如果审批单没有明细，再保留单一分类输入。

### 2. 保存逻辑

- 只提交选中的明细分类。
- 逐条保存到对应 `ExpenseItem`。
- 不对审批主单强行写一个覆盖性的分类。

### 3. 展示逻辑

- 审批明细表里显示：
  - 费用内容
  - 金额
  - 分类
  - 报销凭证
- 报销凭证优先显示附件预览或可点击链接。

### 4. 兼容规则

- 已有对账记录继续保持可编辑。
- 没有明细的审批单仍按单条分类处理。
- 现有匹配状态逻辑不变。

## 需要确认的点

1. 批量分类的操作入口放在表格上方，还是放在明细行右侧。
2. 报销凭证展示是只显示数量，还是直接展开可点开链接。
3. 没有明细时，是否保留当前单一分类字段。
