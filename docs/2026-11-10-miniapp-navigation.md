# 小程序导航及未封账数据展示

日期：2026-11-10。用户截图要求替代此前“只看已封账月份”的规则。

## 页面

- 底部固定为报表、银行流水、分红管理、我的；登录后进入报表。删除独立门店菜单页。
- 报表内只有财务报表、营业收入。三个业务入口共用门店选择器，左上角切换并记住门店，再次进入时校验授权范围和刷新数据。
- 报表、营业收入、费用明细、分红允许查看已创建的未封账账期。财务报表展示封账状态，未封账数据仍会更新；尚未创建的月份返回 404。
- 银行流水不加载月份，不依赖封账、不限制账期；保留发生日期和关联状态筛选、分页、业务详情。
- 只读及门店/分组权限保持不变，无任何新增写入口。

## 银行流水故障原因

小程序通过 Python 直接调用管理端流水列表函数，绕过了 FastAPI 的 response_model 转换，分页结果保留了 ORM BankTransaction 对象。有数据时序列化抛出 PydanticSerializationError 并返回 500；无数据时不会触发。现显式转换为 BankTransactionRead，再构造类型化分页对象。新增 31 条流水的分页回归，覆盖无账期门店和跨月发生日期。

## 数据展示

沿用财务报表及 supplement 服务，实收字段修正为 revenue_net_amount（原 net_income_amount 为净收益，不能用作实收）。补充分类占营业收入/总支出比例及历史累计、计提调整明细、外借款应收、筹建超支补充。银行余额注明截至日期；分红未锁定记录不再标成“已出账”。
