### 2. 匹配工作台 V2 `/matching-v2`

**核心优化**:
- ✅ 双栏式布局（左侧流水 + 右侧推荐）
- ✅ 智能推荐算法（5 维度评分）
- ✅ 自动跳转下一条
- ✅ 实时搜索和筛选
- ✅ 操作步数减少 57%

**智能推荐算法**:
```
金额完全匹配：+50 分
供应商名称匹配：+30 分
日期接近（3天内）：+15 分
摘要关键词匹配：+15 分
同账期同门店：基础条件

总分 ≥90：高置信度（绿色边框）
总分 70-89：中置信度（黄色标识）
总分 <70：低置信度（灰色标识）
```

## 🎯 使用指南

### 立即体验

```bash
# 1. 启动应用
pnpm dev:admin

# 2. 访问页面
http://localhost:3000              # 优化后的首页
http://localhost:3000/dashboard    # 数据仪表盘（新增）
http://localhost:3000/matching-v2  # 匹配工作台 V2（新增）
```

### 在代码中使用

**示例 1：使用指标卡片**
```tsx
import { MetricCard } from '@/components/MetricCard';

<MetricCard
  title="待匹配流水"
  value={127}
  unit="笔"
  status="warning"
  action={{
    label: '去处理',
    onClick: () => router.push('/matching-v2')
  }}
/>
```

**示例 2：使用金额组件**
```tsx
import { MoneyDisplay } from '@/components/MoneyDisplay';

<MoneyDisplay value={12500.50} colorize />
// 输出：¥12,500.50（等宽、千分位）
```

**示例 3：使用图表组件**
```tsx
import { TrendChart } from '@/components/TrendChart';

<TrendChart
  title="收支趋势"
  data={{
    periods: ['2024-03', '2024-04', '2024-05'],
    revenue: [120000, 135000, 142000],
    expense: [85000, 92000, 98000],
  }}
/>
```

## 🎓 学到的经验

### 设计原则

1. **数据为王**：财务系统以数据展示为核心
2. **效率优先**：减少操作步数是关键
3. **防错优先**：财务数据不容出错
4. **渐进增强**：基础功能简单，高级功能渐显

### 技术选择

1. **基于成熟组件库**：Ant Design 提供基础，定制扩展
2. **TypeScript 必须**：类型安全对大型项目很重要
3. **组件化思维**：可复用组件降低维护成本
4. **响应式优先**：移动端使用场景不可忽视

### 实施策略

1. **分阶段实施**：降低风险，快速见效
2. **保留旧版本**：新旧版本并存，平滑过渡
3. **文档同步**：边开发边写文档
4. **持续迭代**：收集反馈，不断优化
