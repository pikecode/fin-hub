# 项目修改记录

项目所有代码修改、功能完善、缺陷修复、部署发布和运维调整统一记录在本文档。本文档按时间倒序维护，最新记录放在最上面。

## 维护规则

1. 日期按倒序排列，最新日期在前。
2. 同一天内按具体时间倒序排列，最新记录在前。
3. 每条记录必须包含：时间、耗时、类型、内容、验证、结果和回滚或注意事项。
4. 时间统一使用 `Asia/Shanghai` 时区，格式为 `YYYY-MM-DD HH:mm`；无法精确时注明“约”。
5. 耗时从开始检查、分析或编辑算起，直到验证完成；不能留空。
6. 验证必须写明实际执行的命令、测试或线上检查及结果；未验证的内容必须明确标注。
7. 部署记录必须写明环境、服务、版本或镜像标签、数据库迁移状态和回滚方式。
8. 复杂方案、部署手册和长期运维流程可以单独成文，但必须在本记录中关联，不能替代本记录。
9. 不记录密码、令牌、生产数据库连接串等敏感信息；需要说明时只写脱敏后的环境或资源标识。
10. 新记录插入最顶部，不在文档末尾追加，以保持倒序。
