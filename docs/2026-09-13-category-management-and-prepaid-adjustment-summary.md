# 分类管理与门店预充值调整开发总结

## 需求背景

本次调整包含三项内容：统一限制费用分类名称重复；优化分类列表中启用和停用分类的展示顺序；将预充值业务从旧的“食材成本 / 快驴充值”调整为一级分类“门店预充值”。

## 分类名称规则

新增和编辑费用分类时，分类名称在全部分类范围内必须唯一，不再只校验同一上级分类下是否重复。

重复名称由 API 统一校验，返回 HTTP 409 和“分类名称已存在”。前端沿用统一错误提示，新增和编辑都会受到相同规则约束。

## 分类列表排序

分类接口和管理页面都将停用分类排到启用分类之后。

同一状态内继续按照分类的排序值和创建时间排序；一级分类的子分类也使用相同的状态优先规则。

## 门店预充值分类口径

新的预充值排除规则为：

```text
category_l1 == "门店预充值"
```

一级分类“门店预充值”下的所有二级分类都会从以下统计中排除：

- 门店总览的本期支出
- 食材成本
- 毛利计算
- 支出分类统计

历史数据中的“食材成本 / 快驴充值”仍保留兼容排除逻辑，避免历史预充值重新计入报表。

## 数据清理

已从当前开发数据库删除分类定义“食材成本 / 快驴充值”。

清理范围仅为分类主数据，保留历史费用记录及其分类快照，不删除银行流水、审批单或费用业务数据。当前“门店预充值 / 快驴充值”分类继续保留。
