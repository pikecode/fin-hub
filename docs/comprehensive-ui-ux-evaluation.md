### 7. 加载与性能 (8.0/10) ⚠️

**当前状态**：

| 指标 | 现状 | 目标 | 差距 |
|-----|------|------|------|
| 首屏加载 | ~2s | <1s | 需优化 |
| 表格渲染 | 基本流畅 | 流畅 | 可优化 |
| 图片加载 | 无懒加载 | 懒加载 | 需实现 |
| 骨架屏 | 部分有 | 全覆盖 | 30% |
| 虚拟滚动 | 无 | 大数据支持 | 未实现 |

**问题**：
- ❌ 无骨架屏（大部分页面）
- ❌ 大数据表格卡顿（1000+ 行）
- ❌ 图片无懒加载
- ❌ 无请求缓存（SWR/React Query）
- ❌ 无乐观更新

**优化建议**：
```tsx
// 1. 骨架屏
{isLoading ? <Skeleton active /> : <Content />}

// 2. 虚拟滚动（处理大数据）
import { VirtualTable } from 'rc-virtual-list';

// 3. 图片懒加载
<Image loading="lazy" placeholder={<Skeleton.Image />} />

// 4. 请求缓存
import useSWR from 'swr';
const { data } = useSWR('/api/stores', fetcher);
```

**缺失功能**：
```tsx
// 1. 全局错误边界

</ErrorBoundary>

message.error({
  content: '操作失败，请重试',
  duration: 5,
  action: <Button onClick={retry}>重试</Button>
});

// 3. 错误日志上报
Sentry.captureException(error);
```
