# 门店筹建费用开发实施计划

日期：2026-10-04。依据：[需求与设计评审稿](2026-10-04-store-preopening-expense-requirements-design.md)。用户已授权按文档开始开发；不包含自动提交或生产部署。

## 实施口径

审批费用原额按整单去重计入筹建报表，分类使用明细原额；付款匹配金额仅用于对账。公司共用独立筹建分类；门店入口包含报表、对账；无账期；封账后不解封；第一期不导出。

## 实施顺序

| 阶段 | 实施内容 | 验证 |
| --- | --- | --- |
| 1 | 数据库迁移、模板标记与历史归属处理、独立分类 | 默认日常不变；已匹配模板切换被拒绝；同步不覆盖配置 |
| 2 | 筹建候选、确认与撤销接口、共享流水占用、日常隔离 | 整单互斥；无账期；分类必选二级；多笔匹配只统计一次 |
| 3 | 门店入口、报表、匹配弹窗、凭证与分类维护页面 | 不显示月份；图片预览；请求 loading 与错误反馈 |
| 4 | 封账保护、日常统计与共享流水回归 | 封账修改被拒绝；银行余额不变；日常报表不混入 |
| 5 | 本地验收、文档完成记录；用户要求后部署 | 类型检查、后端集成测试、迁移验证、生产构建 |

## 技术安排

- 复用审批实例、费用明细、附件和 ExpenseBankMatch，不新建重复同步任务。
- 模板新增筹建布尔标记；审批及费用明细保存 operating/preopening 范围；旧数据默认 operating。
- 独立筹建分类表；费用明细保存筹建二级分类 ID 与名称快照，不改写日常分类字段。
- 门店筹建状态表使用门店唯一约束；匹配记录新增业务范围，筹建 accounting_period 为空。
- 模板切换检查候选／确认占用，事务内更新未占用历史实例与明细；存在占用时返回中文错误。
- 筹建确认锁定门店筹建状态、审批实例、流水；日常确认同样锁定审批和流水并检查业务范围。
- 分类、报表和对账接口放在独立 preopening 模块；沿用分类、报表、对账管理员权限与门店访问权限。
- 报表先取得仍有有效筹建匹配的审批集合，再取得有效费用明细，按实例／明细去重，不能求匹配金额之和。
- 封账阻止匹配、撤销、分类归属修改和关联流水变更；后台同步仅保留来源变化，不覆盖封账明细。
- 日常候选、统计、导出和分红来源排除筹建范围，不能只隐藏前端。

## 数据迁移与上线

1. 新增 Alembic 版本，旧字段默认维持日常业务；测试库验证升级／降级。
2. 本地代码验证后再升级目标环境，禁止开发时直接迁移生产数据库。
3. 管理员维护分类并标记筹建模板；检查未匹配历史审批归属。
4. 生产部署前备份；后端数据库迁移先完成，再启用前端。
5. 若回滚，保留已有筹建数据；有新增业务数据时不直接执行破坏性 downgrade。

## 必测清单

- 默认模板、历史审批仍为日常；标记切换覆盖未占用历史单据；重新同步保留归属。
- 一级分类拒绝匹配；重名、停用、已引用删除有反馈。
- 不同门店、撤销审批、特殊流水、跨模块占用均拒绝。
- 部分付款按审批原额统计；多流水只统计一次；撤销最后一个匹配才移除费用。
- 已封账记录不能确认、撤销、改分类或通过其他入口修改关联数据。
- 筹建费用与日常费用不混算；银行余额仍按真实收付款计算。
- 钉钉占位附件直接预览，普通文件打开；本地附件下载。

### 对账交互对齐

筹建对账调整为与日常审批单对账相同的左右两栏：左侧选择银行流水，右侧按推荐度展示审批候选，支持编号搜索、选中和查看明细；确认匹配后进入独立“匹配并分类”弹窗。弹窗复用银行流水／审批摘要卡、明细分类表和凭证缩略图样式，支持勾选明细批量设置二级分类。无入账月份，保留独立筹建分类和审批原额统计口径。默认匹配金额不超过流水金额及审批尚未付款余额。

类型检查与本地页面编译验证通过。自动浏览器启动受当前环境限制失败，完整浏览器点击与视觉验收未完成。

### 钉钉审批列表分页优化

审批列表由进入时全量下载后本地分页，改为接口分页，默认 20 条；翻页、调整每页数量、模板和状态筛选、编号／申请人／部门搜索均重新查询对应数据。保留总数，当前页已通过数量注明范围；列表 loading 独立于配置和同步任务请求；旧请求返回不覆盖新的页面或筛选结果。解析规则样例独立请求一条，避免分页后缺失样例。接口返回实际限制后的 page_size，并补充固定排序。

本地验证首屏返回 20 条，总数 3215；组合筛选返回 11 条均为已通过。56 项相关后端回归测试与前端类型检查通过。门店审批列表原有漏加载的 6 条历史记录已单独修复。
