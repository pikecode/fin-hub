# 门店套帐端到端验收清单

更新时间：2026-09-01

## 1. 验收目标

验证财务维护人员可以围绕一个门店完成一个账期的完整处理：

登录后台 -> 进入门店套帐 -> 维护银行流水 -> 查看审批单 -> 维护营业收入 -> 完成收入和支出对账 -> 封账 -> 查看报表。

## 2. 验收前准备

### 2.1 账号

- 管理员账号：用于创建门店、账套、用户、收入渠道和股东授权。
- 财务维护账号：只授权一个或少数门店，用于验证门店范围。
- 股东授权码：用于验证小程序只能看已封账报表。

### 2.2 基础数据

建议准备一个独立验收门店：

- 门店名称：`蘑说主流程验收店`
- 账期：`2026-08`
- 收入渠道：`美团验收`
- 渠道规则：`requires_bank_match=true`

建议准备以下业务数据：

| 类型 | 日期 | 金额 | 说明 |
| --- | --- | ---: | --- |
| 营业收入 | 2026-08-20 | 经营收入 1000.00，实收 970.00，手续费 30.00 | 用于收入对账 |
| 银行收入流水 | 2026-08-21 | 970.00 | 关联营业收入 |
| 支出明细 | 2026-08-20 | 300.00 | 用于支出对账 |
| 银行支出流水 | 2026-08-22 | 300.00 | 关联支出明细 |

## 3. 后台验收路径

### 3.1 登录和门店范围

验收步骤：

1. 管理员创建两个门店。
2. 创建财务维护账号，只授权其中一个门店，并授予门店、银行流水、收入、对账、报表相关权限。
3. 使用财务维护账号登录后台。
4. 进入 `/store-ledgers`。

验收结果：

- 门店套帐入口只展示授权门店。
- 未授权门店不应出现在入口卡片中。
- 直接访问未授权门店的工作台 API 应返回 403。

对应接口：

- `GET /api/auth/me`
- `GET /api/auth/me/stores`
- `GET /api/store-ledgers/{store_id}/workspace`

### 3.2 进入门店套帐

验收步骤：

1. 点击授权门店卡片。
2. 切换到账期 `2026-08`。
3. 查看工作台指标和四个业务入口。

验收结果：

- 页面 URL 固定门店 ID。
- 账期切换后指标同步变化。
- 银行流水、审批单、对账、营业收入入口都带入当前门店和账期。

### 3.3 营业收入维护

验收步骤：

1. 进入营业收入管理。
2. 新增 `美团验收` 渠道收入。
3. 输入经营收入 1000.00、实收 970.00。
4. 检查手续费和费率展示。

验收结果：

- 手续费推算为 30.00。
- 费率约为 3.00%。
- 收入记录出现在当前门店和账期列表。
- 需要银行对账的渠道在未关联流水前应显示未对账状态。

对应接口：

- `GET /api/revenue-channels`
- `POST /api/revenue-records`
- `GET /api/revenue-records?store_id=&ledger_period=`

### 3.4 银行流水维护

验收步骤：

1. 进入银行流水管理。
2. 新增或导入一条收入流水 970.00。
3. 新增或导入一条支出流水 300.00。
4. 查看最近导入批次。

验收结果：

- 银行流水列表按当前门店和账期过滤。
- 导入模板可下载。
- 导入预览能展示可导入、重复和错误行。
- 误导入且未参与对账的批次可以回滚。
- 已存在候选、确认或拒绝匹配记录的批次不能回滚。

对应接口：

- `POST /api/bank-transactions`
- `POST /api/bank-transactions/import/preview`
- `POST /api/bank-transactions/import`
- `GET /api/bank-transactions/import/template.csv`
- `POST /api/bank-transactions/imports/{job_id}/rollback`

### 3.5 审批单管理

验收步骤：

1. 进入审批单管理。
2. 按当前门店查看审批单。
3. 切换账期或刷新列表。

验收结果：

- 列表只展示当前门店审批单。
- 账期筛选结果和提交时间月份一致。
- 审批附件状态可识别。

对应接口：

- `GET /api/dingtalk/approval-instances?store_id=`
- `GET /api/attachments?resource_type=approval_instance&resource_id=`

### 3.6 收入对账

验收步骤：

1. 在营业收入列表中选择收入记录。
2. 关联收入方向银行流水 970.00。
3. 确认收入匹配。

验收结果：

- 收入匹配生成候选后可确认。
- 确认后银行流水 `matched_amount` 等于 970.00。
- 收入渠道汇总中已对账金额为 970.00。
- 收入对账完成率为 100.00%。

对应接口：

- `POST /api/matches/revenue`
- `POST /api/matches/revenue/{match_id}/confirm`
- `GET /api/matches/revenue?store_id=&ledger_period=`

### 3.7 支出对账

验收步骤：

1. 创建或同步一条支出明细 300.00。
2. 关联支出方向银行流水 300.00。
3. 确认支出匹配。

验收结果：

- 支出匹配确认成功。
- 支出明细付款状态变为已付款。
- 银行流水 `matched_amount` 等于 300.00。

对应接口：

- `POST /api/expense-items`
- `POST /api/matches`
- `POST /api/matches/{match_id}/confirm`

### 3.8 封账

验收步骤：

1. 回到门店套帐工作台或账套管理。
2. 查看封账预检。
3. 确认封账。
4. 封账后尝试新增支出、收入和银行流水。

验收结果：

- 收入已对账、支出已付款、银行流水已完全匹配时，封账预检通过。
- 封账成功后账套状态为 `closed`。
- 封账后新增支出、收入、银行流水均返回 409。

对应接口：

- `GET /api/ledgers/{ledger_id}/close-check`
- `POST /api/ledgers/{ledger_id}/close`

### 3.9 后台报表

验收步骤：

1. 进入财务报表。
2. 选择验收门店和账期。
3. 查看账套明细和渠道分析。
4. 导出 CSV / Excel。

验收结果：

- 收入金额为 1000.00。
- 支出金额为 300.00。
- 利润为 700.00。
- 收入渠道已对账金额为 970.00。
- CSV / Excel 能正常下载且包含收入渠道汇总。

对应接口：

- `GET /api/reports/ledger-detail`
- `GET /api/reports/ledger-detail.csv`
- `GET /api/reports/ledger-detail.xlsx`

## 4. 股东小程序验收路径

验收步骤：

1. 管理员为验收门店创建股东授权码。
2. 使用授权码登录小程序。
3. 进入门店列表。
4. 选择已封账账期。
5. 查看门店汇总、趋势和渠道分析。

验收结果：

- 只能看到授权门店。
- 只能看到已封账账期。
- 金额与后台同门店同账期报表一致。
- 未授权门店和未封账账期不能通过接口读取。

对应接口：

- `POST /api/shareholder-auth/login`
- `GET /api/shareholder-auth/me`
- `GET /api/reports/store-summaries`
- `GET /api/reports/periods`
- `GET /api/reports/ledger-summary`
- `GET /api/reports/ledger-detail`
